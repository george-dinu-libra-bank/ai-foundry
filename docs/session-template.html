A subsection in code

first_call.py 
from azure.ai.inference import ChatCompletionsClient
from azure.identity import DefaultAzureCredential

client = ChatCompletionsClient(
    endpoint="https://<your-project>.services.ai.azure.com/models",
    credential=DefaultAzureCredential(),
)
resp = client.complete(model="gpt-5.1", messages=[
    {"role": "user", "content": "Say hello from Foundry."}
])
print(resp.choices[0].message.content)

Good habit

We sign in without keys — DefaultAzureCredential everywhere, from the very first call.
